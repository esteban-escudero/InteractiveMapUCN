# Roadmap del Proyecto

Este documento describe la visión a futuro y las funcionalidades planificadas para las próximas versiones de InteractiveMapUCN.

## Próxima Versión (v1.1.0) - Q1 2026

### Mejoras en Navegación
- [ ] **Indicaciones Paso a Paso**: Instrucciones textuales detalladas (ej. "Gira a la derecha en 50 metros").
- [ ] **Tiempo Real**: Mostrar posición del usuario actualizándose en tiempo real mientras camina.

### Administración
- [ ] **Importación Masiva**: Permitir subir archivos CSV/Excel para crear múltiples salas o edificios de una vez.
- [ ] **Papelera de Reciclaje**: Capacidad de restaurar edificios o rutas eliminados accidentalmente.

---

## Futuro (v2.0.0) - Q3 2026

### Integración Académica
- [ ] **Buscador de Horarios**: Integración con API de UCN para mostrar dónde es la próxima clase del estudiante.
- [ ] **Disponibilidad de Salas**: Visualizar en el mapa si una sala de estudio o laboratorio está ocupado.

### Social
- [ ] **Eventos en Mapa**: Mostrar eventos universitarios (ferias, charlas) geolocalizados en el mapa.
- [ ] **Reportes de Usuario**: Permitir que los estudiantes reporten problemas de infraestructura (ej. "Ascensor malo") directamente en el mapa.

### Técnico
- [ ] **Mapas 3D**: Implementación de una vista 3D de los edificios principales usando Mapbox GL o Three.js.
- [ ] **Notificaciones Push**: Avisos de eventos o emergencias cercanas.

---

## Ideas en Evaluación

- Integración con realidad aumentada (AR) para navegación interior.
- Versión nativa (React Native) para iOS y Android.
- Modo "Tour Virtual" con fotos 360° de los puntos de interés.
