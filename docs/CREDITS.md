## Tecnologías y Librerías

Este proyecto ha sido posible gracias al increíble trabajo de la comunidad de código abierto.

### Frontend
- **React**: Biblioteca para interfaces de usuario.
- **Leaflet**: Mapas interactivos open-source.
- **react-leaflet**: Componentes de React para Leaflet.
- **Turf.js**: Análisis geoespacial avanzado en el navegador.

### Backend
- **Node.js**: Entorno de ejecución.
- **Express**: Framework web rápido y minimalista.
- **PostgreSQL**: Base de datos relacional avanzada.
- **PostGIS**: Extensor de base de datos espacial para PostgreSQL.
- **bcryptjs**: Hashing de contraseñas.
- **jsonwebtoken**: Implementación de tokens de acceso JSON.

### Infraestructura/Herramientas
- **Docker**: Plataforma de contenerización.
- **Nginx**: Servidor web y proxy inverso.
- **PM2**: Gestor de procesos para Node.js.
