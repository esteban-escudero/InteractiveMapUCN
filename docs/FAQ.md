# ❓ Preguntas Frecuentes (FAQ)

## 👤 Generales (Usuarios)

### ¿Necesito internet para usar el mapa?
La primera vez que entras, sí. Después, la aplicación guarda los datos básicos y funciona **Offline** (sin internet), aunque algunas funciones como "Mi ubicación" o cargar nuevas imágenes pueden requerir conexión.

### ¿La aplicación consume muchos datos?
No. InteractiveMapUCN es una PWA ligera. Los mapas base se cargan bajo demanda y se guardan en caché para ahorrar datos en futuras visitas.

### ¿Puedo compartir mi ubicación con un amigo?
Actualmente no es posible compartir tu ubicación en tiempo real dentro de la app, pero puedes compartir el enlace de un edificio específico copiando la URL del navegador.

### ¿Por qué mi ubicación GPS no es exacta?
La precisión depende del GPS de tu teléfono. Dentro de edificios (interiores), la señal GPS suele ser débil o inexacta. Recomendamos usar el mapa visualmente para orientarse en interiores.

### ¿Cómo reporto un error en el mapa?
Si ves un nombre de sala incorrecto o una ruta cerrada, por favor envía un correo a [soporte.mapa@ucn.cl](mailto:soporte.mapa@ucn.cl) con los detalles.

## 🔧 Técnicas (Ayuda)

### ¿Qué navegadores son compatibles?
La aplicación funciona en las últimas versiones de:
- Google Chrome (Android/PC/Mac)
- Safari (iOS/Mac)
- Mozilla Firefox
- Microsoft Edge

### ¿Por qué no recibo notificaciones?
Por ahora el sistema no envía notificaciones push. Esta función está planeada para futuras actualizaciones.

### La aplicación no carga o se ve en blanco
Intenta lo siguiente:
1. Recarga la página.
2. Borra la caché del navegador.
3. Verifica tu conexión a internet.
